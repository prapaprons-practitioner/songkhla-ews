# บันทึกเหตุน้ำท่วมจริง

ระบบใช้บันทึกนี้ตรวจว่าเตือนทันหรือไม่ ผลแสดงในแท็บ "ช่องว่างข้อมูล" การ์ด "เหตุน้ำท่วมจริงเทียบกับการเตือน"

## ทางที่ 1: เพิ่มแถวในไฟล์ `reports/flood_reports.csv` (ผู้ดูแล)

เปิดไฟล์ใน GitHub → กดรูปดินสอ → เพิ่มบรรทัดใหม่ท้ายไฟล์ → Commit changes ระบบนับทุกแถวในไฟล์นี้ว่าตรวจแล้ว

| คอลัมน์ | ใส่อะไร | ตัวอย่าง |
|---|---|---|
| time | วันเวลา (ค.ศ. หรือ พ.ศ. ก็ได้) | `2026-11-24 21:30` หรือ `24/11/2569 21:30` หรือ `2026-11-24` |
| time_quality | `onset` = เวลาที่น้ำเริ่มท่วม · `observed` = เวลาที่พบหรือเวลาที่ข่าวรายงาน (น้ำอาจท่วมก่อนนั้น) · `day` = ทราบแค่วัน | `observed` |
| province, amphoe, tambon | ชื่อจังหวัด อำเภอ ตำบล (ไม่รู้ตำบลให้เว้นว่าง ระบบจะดูทั้งอำเภอ) | `สงขลา,หาดใหญ่,คอหงส์` |
| place | สถานที่ ถนน ชุมชน | `ถนนกาญจนวนิช หน้าตลาด...` |
| depth_cm | ความลึกโดยประมาณ (ซม.) ไม่รู้ให้เว้นว่าง | `30` |
| source | ลิงก์ข่าว โพสต์ หรือภาพ | `https://...` |
| note | หมายเหตุ | |

ข้อความที่มีจุลภาค (,) ให้ครอบด้วยเครื่องหมายคำพูด เช่น `"ถนนนิพัทธ์อุทิศ 1, 2, 3"`

## ทางที่ 2: Google Form ให้ประชาชนแจ้ง (ไม่บังคับ)

1. สร้าง Google Form ปิด "รวบรวมอีเมล" แล้วตั้งคำถามตามนี้ (ชื่อคำถามต้องมีคำที่ขีดเส้นใต้ ระบบใช้คำนี้จับคอลัมน์)
   - **วันเวลา**ที่น้ำท่วม — แบบวันที่ + เวลา (บังคับ)
   - **ชนิดเวลา** — ตัวเลือก: `เวลาที่เริ่มท่วม` / `เวลาที่พบหรือรายงาน` / `ทราบแค่วัน`
   - **จังหวัด** — ตัวเลือก
   - **อำเภอ** — ข้อความสั้น (บังคับ)
   - **ตำบล** — ข้อความสั้น
   - **สถานที่** / จุดสังเกต — ข้อความสั้น
   - **ความลึก**โดยประมาณ (ซม.) — ตัวเลข
   - **ลิงก์**ภาพหรือข่าว (ถ้ามี)
   - **หมายเหตุ**
   - คำอธิบายบนแบบฟอร์ม: "คำตอบจะเผยแพร่สาธารณะ ไม่ต้องใส่ชื่อ เบอร์โทร หรือภาพที่เห็นหน้าคน"
2. แท็บ "คำตอบ" → ลิงก์ไปยังชีต แล้วเพิ่มคอลัมน์ชื่อ **ตรวจแล้ว** ทางขวาสุด ใส่ `ใช่` ในแถวที่ตรวจแล้วว่าเป็นเหตุจริง ระบบนับคะแนนเฉพาะแถวที่ใส่ `ใช่` แถวอื่นแสดงเป็น "รอตรวจ"
3. ในชีต: ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ → เลือกชีตคำตอบ → รูปแบบ "ค่าที่คั่นด้วยจุลภาค (.csv)" → เผยแพร่ → คัดลอกลิงก์
4. แก้ `config.json` ส่วน `flood_reports`
   - `form_url`: ลิงก์แบบฟอร์ม (ปุ่ม "แจ้งเหตุน้ำท่วมที่เห็นจริง" จะขึ้นในหน้าภาพรวม)
   - `form_csv_url`: ลิงก์ CSV จากข้อ 3

## ระบบให้คะแนนอย่างไร

- **เตือนทัน**: ตำบลนั้น (หรือตำบลใดในอำเภอ ถ้าไม่ระบุตำบล) ขึ้นถึงระดับเตือนภัยภายใน 24 ชม. ก่อนเวลาน้ำท่วม
- **เฝ้าระวังเท่านั้น**: ขึ้นถึงแค่เฝ้าระวัง
- **พลาด**: ไม่มีการเตือนเลย
- **เตือนก่อน**: เวลาน้ำท่วม − ครั้งแรกที่ขึ้นระดับในช่วง 24 ชม. นั้น ถ้าเป็นเวลาที่พบ/รายงาน จะแสดงเป็น "ไม่เกิน X ชม." ถ้าขึ้นระดับไว้ตั้งแต่ก่อนช่วงนั้นแสดงเป็น "24+ ชม."
- การขึ้นระดับเตือนภัยที่ไม่มีรายงานน้ำท่วมในอำเภอเดียวกันภายใน 36 ชม. นับเป็น "ยังไม่มีรายงานยืนยัน" ไม่ได้แปลว่าเตือนผิด เพราะอาจไม่มีคนแจ้ง
- ระบบเก็บประวัติระดับรายตำบลใน `data/level_log.json` ตั้งแต่ fix13 ก่อนหน้านั้นตรวจได้จากประวัติการแจ้งเตือน (เฉพาะระดับเตือนภัยขึ้นไป)
