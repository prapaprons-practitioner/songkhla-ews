# เตือนน้ำท่วมล่วงหน้า: สงขลาและจังหวัดที่มีพรมแดนติดกัน (ต้นแบบ)

หน้าเว็บติดตามความเสี่ยงน้ำท่วม **รายจังหวัด → อำเภอ → ตำบล → ถนน**
ครอบคลุมสงขลาและ 5 จังหวัดที่มีพรมแดนติดกัน คือ สตูล พัทลุง ปัตตานี ยะลา และนครศรีธรรมราช
(571 ตำบล 77 อำเภอ) อัปเดตอัตโนมัติทุก 30 นาที ใช้ข้อมูลเปิดที่ไม่ต้องเสียค่าใช้จ่าย

> **ต้นแบบทดลอง ไม่ใช่ประกาศทางการ** เกณฑ์เตือนภัยเป็นค่าเริ่มต้นที่ยังไม่ได้ปรับเทียบกับเหตุการณ์จริง
> ใช้ประกอบการเฝ้าระวัง และติดตามประกาศของจังหวัดและ ปภ. เสมอ

```
GitHub Actions (ทุก 30 นาที)
  ├─ ดึง: ระดับน้ำ + ฝน (สสน.) · ฝนพยากรณ์ 3 โมเดล + ความชื้นดิน (Open-Meteo) · พื้นที่เสี่ยงน้ำป่า (สสน. FEWS)
  ├─ คำนวณระดับเตือนภัยรายตำบล → ถนนที่ผ่านตำบลนั้น
  ├─ ส่งแจ้งเตือนเข้ามือถือ (ถ้าตั้งค่า)
  └─ เผยแพร่ → GitHub Pages (หน้าเว็บ)
```

## ระบบคำนวณอะไร

ทุกตำบลได้ระดับ **ปกติ / เฝ้าระวัง / เตือนภัย / วิกฤต** จากปัจจัยที่สูงที่สุดใน 4 ข้อนี้ และหน้าเว็บแสดงเหตุผลทุกข้อ

| ปัจจัย | คำนวณจาก | ระดับ |
|---|---|---|
| ฝน (ระดับอำเภอ) | ฝนพยากรณ์ 24 ชม. เฉลี่ย 3 โมเดล และฝนสะสม (ฝนที่ตกแล้ว 24 ชม. + ฝนพยากรณ์ 48 ชม.) | ตามเกณฑ์ใน `config.json` ถ้าดินอิ่มน้ำจะขยับจากเฝ้าระวังเป็นเตือนภัย |
| สถานีวัดระดับน้ำในตำบล | ระยะจากผิวน้ำถึงตลิ่ง อัตราน้ำขึ้น (3 ชม.ล่าสุด) และ**เวลาที่จะถึงตลิ่งถ้าขึ้นต่อในอัตราเดิม** | ถึงตลิ่ง = วิกฤต · ใกล้ตลิ่งหรือจะถึงใน 12 ชม. = เตือนภัย |
| น้ำจากต้นน้ำ | ห่วงโซ่สถานี เช่น X.173A สะเดา → X.90 คลองหอยโข่ง → X.44 หาดใหญ่ | ต้นน้ำล้นตลิ่ง → ตำบลปลายน้ำได้ระดับเตือนภัย พร้อมเวลาโดยประมาณที่น้ำจะถึง |
| น้ำป่า | รายชื่อตำบลเสี่ยงน้ำท่วมฉับพลันของ สสน. | อย่างน้อยเฝ้าระวัง |

ถนนได้ระดับตามตำบลที่ผ่าน เช่น ทางหลวงหมายเลข 4 ช่วงที่ผ่านตำบลระดับวิกฤตจะแสดงเป็นสีแดง

## ขั้นตอนติดตั้งบน GitHub (ทำผ่านหน้าเว็บทั้งหมด ประมาณ 20 นาที)

### ขั้นที่ 1: สร้าง repository
1. เข้า https://github.com แล้วล็อกอิน
2. มุมขวาบน กด **+** → **New repository**
3. ชื่อ: `songkhla-ews` · เลือก **Public** (บัญชีฟรีใช้ GitHub Pages ได้เฉพาะแบบ Public) → **Create repository**

### ขั้นที่ 2: อัปโหลดไฟล์
1. แตกไฟล์ zip ในเครื่อง
2. ในหน้า repo กด **uploading an existing file**
3. ลาก `config.json`, `README.md` และโฟลเดอร์ `scripts`, `site`, `tests` ไปวาง → **Commit changes**

### ขั้นที่ 3: สร้างไฟล์ workflow 3 ไฟล์
โฟลเดอร์ `.github` มักถูกซ่อนในเครื่อง ลากแล้วอาจไม่ติดไปด้วย จึงสร้างทางหน้าเว็บ ทำซ้ำ 3 รอบ:
1. **Add file** → **Create new file**
2. ช่องชื่อไฟล์พิมพ์ `.github/workflows/update.yml`
3. เปิดไฟล์เดียวกันในเครื่องด้วย Notepad / TextEdit คัดลอกทั้งหมดมาวาง → **Commit changes**
4. ทำซ้ำกับ `.github/workflows/roads.yml` และ `.github/workflows/archive.yml`

### ขั้นที่ 4: อนุญาตให้ workflow เขียนไฟล์ได้
**Settings** → **Actions** → **General** → หัวข้อ **Workflow permissions** เลือก **Read and write permissions** → **Save**

### ขั้นที่ 5: รันครั้งแรกและตรวจผล
1. แท็บ **Actions** (ถ้ามีปุ่ม *I understand my workflows…* ให้กดก่อน)
2. เลือก **อัปเดตข้อมูลน้ำ** → **Run workflow** → รอ 2–5 นาที
3. กดเข้าไปที่รอบที่รัน ดูส่วน **Summary** จะมีตาราง "ผลการดึงข้อมูล" ✅/❌ ของแต่ละแหล่ง และภาพรวมจำนวนตำบลแต่ละระดับ
4. ถ้าห่วงโซ่สถานีขึ้นว่า "หาไม่พบ" ดูหัวข้อ "ปรับแต่ง" ด้านล่าง

### ขั้นที่ 6: เปิดหน้าเว็บ
1. **Settings** → **Pages** → Source: **Deploy from a branch** · Branch: **gh-pages** · **/ (root)** → **Save**
2. รอ 1–3 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/songkhla-ews/`
3. ลิงก์รายตำบลแชร์ได้ เช่น `…/songkhla-ews/#t=TH901101` (ต.หาดใหญ่)

### ขั้นที่ 7: สร้างชั้นข้อมูลถนน (ครั้งเดียว)
**Actions** → **สร้างชั้นข้อมูลถนน** → **Run workflow** (ใช้เวลา 3–10 นาที) ระบบดึงถนนสายหลักจาก OpenStreetMap
แล้วแบ่งเป็นช่วงตามตำบล รอบถัดไปของ "อัปเดตข้อมูลน้ำ" จะมีแท็บถนนให้ใช้

### ขั้นที่ 8: เก็บข้อมูลย้อนหลัง (⚠️ ควรทำก่อนกลาง พ.ย. 2569)
สสน. ให้ดึงย้อนหลังได้แค่ 365 วัน ข้อมูลน้ำท่วม 19–30 พ.ย. 2568 จะเริ่มหายจากต้นทางตั้งแต่กลาง พ.ย. 2569
1. **Actions** → **เก็บข้อมูลย้อนหลังและวิเคราะห์เหตุการณ์** → **Run workflow** (ใช้เวลา 10–40 นาที)
2. ข้อมูลรายสถานีจะเก็บในสาขา `archive` ของ repo (ไฟล์ CSV เปิดด้วย Excel ได้)
3. Summary จะแสดง**เวลาเดินทางของน้ำ**ระหว่างสถานีในห่วงโซ่ และสถานีที่น้ำเกินตลิ่งมากที่สุด
4. workflow นี้รันเองทุกเดือน ข้อมูลจะสะสมต่อเนื่องเกิน 365 วัน

### ขั้นที่ 9 (ไม่บังคับ): รับแจ้งเตือนเข้ามือถือ ฟรีผ่านแอป ntfy
1. ติดตั้งแอป **ntfy** (Android / iPhone)
2. ตั้งชื่อหัวข้อที่เดายาก เช่น `songkhla-flood-8f3k2q` (ใครรู้ชื่อนี้ก็สมัครรับได้)
3. ในแอปกด **+** → ใส่ชื่อหัวข้อ → Subscribe
4. ใน GitHub: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
   ชื่อ `NTFY_TOPIC` ค่า = ชื่อหัวข้อ → **Add secret**
5. ระบบจะส่งแจ้งเตือนเมื่อมีตำบล**ขึ้น**ถึงระดับเตือนภัยหรือสูงกว่า (รอบแรกบันทึกเป็นฐาน ไม่ส่ง)

## ปรับแต่ง (`config.json` แก้บนหน้าเว็บ GitHub ได้: เปิดไฟล์ → ไอคอนดินสอ → Commit)

- `thresholds.rain` เกณฑ์ฝน (มม.) · `thresholds.station` เกณฑ์ระดับน้ำ
- `chains` ห่วงโซ่สถานีต้นน้ำ → ปลายน้ำ
  - `match` รหัสสถานี (ระบบหาจากรหัสหรือชื่อสถานีของ สสน.) ถ้าหาไม่พบ ให้ดูรหัสจริงในแท็บ **สถานีวัดน้ำ** บนหน้าเว็บ
  - `lag_h_to_next` เวลาเดินทางของน้ำ (ชม.) ไปสถานีถัดไป ให้ใช้ผลจากขั้นที่ 8 แทนค่าประมาณ
  - `downstream_tambons` ตำบลปลายน้ำที่จะได้รับคำเตือน
- `notify.min_level` ระดับที่เริ่มส่งแจ้งเตือน (2 = เตือนภัย)
- `provinces` รายชื่อจังหวัด (ถ้าเพิ่มจังหวัด ต้องเพิ่มขอบเขตตำบลใน `site/data/static` ด้วย)

## ข้อจำกัดที่ต้องรู้

| ข้อจำกัด | ผลต่อระบบ |
|---|---|
| ตำบลที่มีสถานีวัดระดับน้ำมีน้อย (คาดว่าราว 1 ใน 10) | ตำบลส่วนใหญ่ใช้ได้แค่ฝนพยากรณ์ระดับอำเภอ จึงบอกได้ว่า "ฝนมากเสี่ยงท่วม" แต่ไม่รู้ว่าน้ำจริงอยู่ตรงไหน |
| ฝนพยากรณ์ใช้จุดกึ่งกลางอำเภอ | ทุกตำบลในอำเภอเดียวกันได้ค่าฝนเท่ากัน |
| ไม่มีข้อมูลประตูระบายน้ำ สถานีสูบ ความจุคลองจริง | ยังคำนวณ "คลองรับได้อีกเท่าไร" ไม่ได้ ใช้ระดับตลิ่งแทน |
| ไม่มีระดับน้ำทะเลสาบสงขลาและน้ำขึ้นน้ำลง | ยังไม่ได้คำนวณผลของการระบายลงทะเลสาบ |
| ระดับของถนนอนุมานจากตำบล | ยังไม่ใช่สถานะถนนปิดจริง |
| เกณฑ์เป็นค่าเริ่มต้น | อาจเตือนเกินหรือขาด ต้องปรับจากผลวิเคราะห์ขั้นที่ 8 และบันทึกเหตุการณ์จริง |
| แนวโน้มระดับน้ำต้องใช้ข้อมูล 3 รอบขึ้นไป | ชั่วโมงแรกหลังติดตั้งยังไม่มี "จะถึงตลิ่งในกี่ชั่วโมง" |
| GitHub อาจรันช้าหรือข้ามรอบ และหยุดตารางเองถ้า repo ไม่มีความเคลื่อนไหว 60 วัน | หน้าเว็บแสดงเวลาข้อมูลล่าสุด ถ้าเกิน 90 นาทีจะขึ้นตัวแดง ให้เข้าไปกด Enable workflow |
| ปลายทางของ สสน. ไม่ใช่ API ที่ประกาศรับรองอย่างเป็นทางการ | อาจเปลี่ยนโดยไม่แจ้ง ถ้าจะใช้งานจริงควรขอใช้ข้อมูลจาก สสน. (info_thaiwater@hii.or.th) |

## ถ้ามีปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ขั้นเผยแพร่ล้มเหลว (403) | ทำขั้นที่ 4 แล้วรันใหม่ |
| ไม่มีตัวเลือก gh-pages ในขั้นที่ 6 | ขั้นที่ 5 ยังไม่สำเร็จ ดู log ในแท็บ Actions |
| ❌ ระดับน้ำ / ฝน (สสน.) timeout | ต้นทางขัดข้องชั่วคราว ระบบใช้ข้อมูลรอบก่อน ถ้าล้มเหลวตลอดอาจเพราะปลายทางเปลี่ยน |
| ❌ Open-Meteo (429) | เกินโควตาฟรี ระบบดึงพยากรณ์ใหม่ชั่วโมงละครั้ง ถ้ายังเกินให้เพิ่ม `min_interval_minutes` |
| ❌ พื้นที่เสี่ยงน้ำป่า | ไม่กระทบส่วนอื่น อาจเป็นช่วงที่ สสน. ไม่มีรายงาน |
| ห่วงโซ่สถานี "หาไม่พบ" | สสน. อาจใช้รหัสต่างจากที่ตั้งไว้ ดูชื่อจริงในแท็บสถานีวัดน้ำ แล้วแก้ `match` |
| แท็บถนนว่าง | ยังไม่ได้ทำขั้นที่ 7 หรือรอบ "อัปเดตข้อมูลน้ำ" ถัดไปยังไม่รัน |
